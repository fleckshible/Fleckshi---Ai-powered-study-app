Fleckshi Emoticon Sheet Artwork Placement
=======================================

Copy your supplied 8-column x 4-row emoticon sheet image to:

  public/assets/fleckshi/fleckshi-emotes-source.png

Runtime asset URL used by Vite (base: './'):
  ./assets/fleckshi/fleckshi-emotes-source.png

Expected Grid Layout (8 columns x 4 rows, 32 expressions):
  Row 0: Idle, Happy, Excited, Wink, Cheerful, Curious, Thinking, Confused
  Row 1: Surprised, Shocked, Blushing, Embarrassed, Pouting, Angry, Annoyed, Tired
  Row 2: Sleepy, Sleeping, Relaxed, Relieved, Pleased, Proud, Eating, Drinking
  Row 3: Focused, Working, Helping, Success, Error, Loading, Info, Waiting

Until fleckshi-emotes-source.png is copied here, Fleckshi renders a neutral
typographic "FL" portrait badge with the active expression label so the guide
remains fully usable without fabricated placeholder art.
